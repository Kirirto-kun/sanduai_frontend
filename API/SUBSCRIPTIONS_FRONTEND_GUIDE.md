# Руководство по системе подписок для фронтенда

## Обзор

Система подписок добавляет информацию о подписке пользователя в ответы API. Информация о подписке возвращается вместе с балансом токенов.

---

## Поля подписки

Все ответы с информацией о подписке содержат следующие поля:

- **`has_subscription`** (bool) - активна ли подписка на данный момент
- **`subscription_end`** (string | null) - дата окончания подписки в ISO формате (например, "2026-02-15T00:00:00") или `null` если подписки нет
- **`subscription_plan`** (string) - тип подписки: `"free"` (бесплатная) или `"premium"` (платная)

---

## Публичные эндпоинты (для пользователей)

### GET `/api/tokens/balance`

**Что изменилось:**

Ответ теперь включает информацию о подписке. Поля `has_subscription`, `subscription_end`, `subscription_plan` добавлены к существующим полям `balance` и `user_id`.

**Использование:**

Используйте этот эндпоинт для получения баланса токенов и статуса подписки пользователя. При каждом запросе система автоматически проверяет, не истекла ли подписка, и обновляет её статус при необходимости.

---

## Админ эндпоинты

### POST `/api/admin/users/{user_id}/subscription`

**Описание:**

Выдает подписку пользователю на указанное количество дней. Требует роль администратора.

**Тело запроса:**

```json
{
  "days": 30
}
```

Поле `days` должно быть положительным числом (> 0).

**Логика:**

- Если у пользователя уже есть активная подписка (не истекла) - подписка продлевается от текущей даты окончания
- Если подписка истекла или её нет - создается новая подписка от текущей даты

**Ответ:**

Возвращает `AddSubscriptionResponse` с полями:
- `user_id` - ID пользователя
- `subscription_plan` - тип подписки (обычно `"premium"`)
- `subscription_end` - дата окончания подписки (ISO формат)
- `has_subscription` - статус подписки
- `message` - сообщение об успешной операции

---

### GET `/api/admin/users`

**Что изменилось:**

Каждый пользователь в списке теперь включает поля подписки: `has_subscription`, `subscription_end`, `subscription_plan`.

**Использование:**

При получении списка пользователей система автоматически проверяет и обновляет статусы подписок для всех пользователей в списке. Используйте эти поля для отображения информации о подписке в админ панели.

---

## Типы подписок

- **`"free"`** - бесплатная подписка (по умолчанию для всех пользователей)
- **`"premium"`** - платная подписка (выдается админом)

В будущем могут быть добавлены другие типы (например, `"pro"`, `"enterprise"`).

---

## Логика работы системы

### Автоматическая проверка подписок

Система автоматически проверяет подписки при каждом обращении к эндпоинтам:
- `GET /api/tokens/balance`
- `GET /api/admin/users`

Если подписка истекла (дата окончания в прошлом), она автоматически сбрасывается:
- `subscription_plan` → `"free"`
- `subscription_end` → `null`
- `has_subscription` → `false`

### Продление подписок

При выдаче подписки админом:
- Если подписка активна - добавляется указанное количество дней к текущей дате окончания
- Если подписка истекла или её нет - создается новая подписка на указанное количество дней от текущей даты

---

## Формат даты

Все даты возвращаются в ISO формате: `"YYYY-MM-DDTHH:MM:SS"` (например, `"2026-02-15T00:00:00"`).

Если подписки нет, `subscription_end` будет `null`.

---

## Обработка ошибок

### Выдача подписки (POST `/api/admin/users/{user_id}/subscription`)

- **404** - пользователь не найден
- **403** - недостаточно прав (не админ)
- **422** - невалидные данные (например, `days <= 0`)

---

## Рекомендации для фронтенда

1. **Кеширование**: Информация о подписке может обновляться автоматически, поэтому не кешируйте статус подписки на длительное время

2. **Отображение статуса**: Используйте поле `has_subscription` для определения, активна ли подписка, а `subscription_end` - для отображения даты окончания

3. **Проверка подписки**: Если нужно ограничить доступ к функциям по подписке, проверяйте `has_subscription === true`

4. **Форматирование даты**: Используйте `subscription_end` для отображения даты окончания подписки (если не `null`)

5. **Админ панель**: При выдаче подписки через админ панель обновите список пользователей или информацию о конкретном пользователе после успешной операции

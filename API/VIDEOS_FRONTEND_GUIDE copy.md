# Руководство по системе видео для фронтенда

## Обзор

Система видео обеспечивает загрузку и просмотр видео через Bunny CDN. Загрузка видео доступна только администраторам, просмотр - только пользователям с активной подпиской.

---

## Авторизация и доступ

### Загрузка видео (Админ)

Все эндпоинты для загрузки требуют:
- JWT токен с ролью `admin` в заголовке `Authorization: Bearer <token>`

### Просмотр видео (Подписчики)

Все эндпоинты для просмотра требуют:
- JWT токен пользователя в заголовке `Authorization: Bearer <token>`
- Активную подписку (проверяется автоматически)

---

## Админ эндпоинты

### POST `/api/admin/videos/upload-token`

**Описание:**

Создает токен для загрузки видео в Bunny CDN. Используется для инициализации процесса загрузки.

**Тело запроса:**

```json
{
  "title": "Название видео/урока"
}
```

Поле `title` обязательно, максимальная длина 255 символов.

**Ответ:**

Возвращает данные для загрузки видео:
- `bunny_video_id` - ID видео в Bunny CDN (строка)
- `presigned_upload_url` - URL для прямой загрузки файла
- `authorization_header` - Значение для заголовка Authorization при загрузке
- `video_db_id` - ID записи в нашей БД (UUID)

**Использование:**

1. Админ отправляет POST запрос с названием видео
2. Получает `presigned_upload_url` и `authorization_header`
3. Загружает видеофайл напрямую в Bunny CDN через полученный URL
4. Использует `authorization_header` как значение заголовка `Authorization` при загрузке
5. Загружает файл методом PUT на `presigned_upload_url`

**Важно:**

- Файл загружается напрямую в Bunny CDN, минуя ваш сервер
- `authorization_header` уже содержит полный формат: `"AccessKey {api_key}"` - используйте его напрямую в заголовке `Authorization`
- После загрузки Bunny автоматически отправляет вебхук на сервер для обновления статуса
- Статус видео изменится с `uploading` на `processing`, затем на `ready` когда видео будет готово

**Формат загрузки:**

- Метод: `PUT`
- URL: `presigned_upload_url` из ответа
- Заголовок: `Authorization: {authorization_header}` (уже содержит "AccessKey" префикс)
- Тело: бинарный файл видео (Content-Type определится автоматически)

**Ошибки:**

- 403 - недостаточно прав (не админ)
- 502 - ошибка при создании видео в Bunny CDN
- 422 - невалидные данные (например, пустой title)

## Публичные эндпоинты

### POST `/api/webhooks/bunny`

**Описание:**

Эндпоинт для вебхуков от Bunny CDN. Используется Bunny для уведомления о статусе видео.

**Использование:**

Настроить в панели Bunny CDN, чтобы вебхуки отправлялись на этот URL. Не требует авторизации.

**Ответ:**

Всегда возвращает `200 OK` с телом `{"status": "ok"}`

## Эндпоинты для подписчиков

### GET `/api/courses/videos`

**Описание:**

Получает список всех готовых к просмотру видео. Доступен только подписчикам.

**Query параметры:**

- `limit` (необязательный, по умолчанию 50) - максимальное количество записей (1-100)
- `offset` (необязательный, по умолчанию 0) - смещение для пагинации (≥ 0)

**Ответ:**

Возвращает список видео с пагинацией:
- `videos` - массив объектов видео:
  - `id` - ID видео в нашей БД (UUID)
  - `title` - название видео
  - `duration` - длительность в секундах (может быть `null`)
  - `thumbnail_url` - ссылка на превью (может быть `null`)
  - `status` - статус видео (для готовых видео всегда `"ready"`)
  - `created_at` - дата создания (ISO формат)
- `total` - общее количество готовых видео
- `limit` - использованный лимит
- `offset` - использованное смещение

**Сортировка:**

Видео отсортированы по дате создания (новые первые).

**Фильтрация:**

Возвращаются только видео со статусом `"ready"`.

**Ошибки:**

- 401 - не авторизован
- 403 - нет активной подписки
- 422 - невалидные параметры (например, limit > 100)

---

### GET `/api/courses/video/{video_db_id}`

**Описание:**

Получает токен для просмотра конкретного видео. Доступен только подписчикам.

**Path параметры:**

- `video_db_id` - ID видео в нашей БД (UUID)

**Ответ:**

Возвращает данные для просмотра видео:
- `bunny_video_id` - ID видео в Bunny CDN (строка)
- `watch_token` - токен для просмотра (SHA256 хеш)
- `expiration_time` - время истечения токена (Unix timestamp в миллисекундах)
- `playback_url` - **полный URL для просмотра видео с токеном** (готов к использованию)

**Использование:**

1. Получить токен через этот эндпоинт
2. **Использовать `playback_url` напрямую в HTML5 video элементе** (рекомендуется)
3. Или использовать `bunny_video_id` и `watch_token` для ручного формирования URL
4. Токен действителен до `expiration_time` (обычно 60 минут)

**Пример использования на фронтенде:**

```jsx
// React компонент
import { useEffect, useRef, useState } from 'react';

function VideoPlayer({ videoDbId }) {
  const videoRef = useRef(null);
  const [playbackUrl, setPlaybackUrl] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    async function fetchPlaybackUrl() {
      try {
        const response = await fetch(`/api/courses/video/${videoDbId}`, {
          headers: {
            'Authorization': `Bearer ${token}`,
          },
        });
        
        if (!response.ok) {
          throw new Error('Failed to get video token');
        }
        
        const data = await response.json();
        setPlaybackUrl(data.playback_url);
      } catch (err) {
        setError(err.message);
      }
    }
    
    fetchPlaybackUrl();
  }, [videoDbId]);

  if (error) {
    return <div>Error: {error}</div>;
  }

  if (!playbackUrl) {
    return <div>Loading...</div>;
  }

  return (
    <video
      ref={videoRef}
      src={playbackUrl}
      controls
      width="100%"
      height="auto"
      onError={(e) => {
        console.error('Video playback error:', e);
        setError('Failed to load video');
      }}
    >
      Your browser does not support the video tag.
    </video>
  );
}
```

**ВАЖНО:**
- Используйте HTML5 `<video>` элемент с прямым `src={playbackUrl}`
- НЕ используйте embed iframe или `iframe.mediadelivery.net` - это для другого типа интеграции
- `playback_url` уже содержит все необходимые токены и параметры

**Формула токена:**

Токен генерируется по формуле: `SHA256(libraryId + securityKey + expirationTime + videoId)`

**Формат playback_url:**

`https://vz-{library_id}.b-cdn.net/{video_id}/play_480p.mp4?token={token}&expires={expiration_time}`

**Ошибки:**

- 401 - не авторизован
- 403 - нет активной подписки
- 404 - видео не найдено
- 400 - видео не готово к просмотру (статус не `"ready"`)

---

## Статусы видео

- `"uploading"` - видео загружается
- `"processing"` - видео обрабатывается Bunny CDN
- `"ready"` - видео готово к просмотру
- `"error"` - произошла ошибка при обработке

**Для просмотра доступны только видео со статусом `"ready"`.**

---

## Логика работы системы

### Процесс загрузки видео (Админ)

1. Админ отправляет POST `/api/admin/videos/upload-token` с названием видео
2. Получает `presigned_upload_url`, `authorization_header` и `video_db_id`
3. Загружает видеофайл напрямую в Bunny CDN (PUT запрос на `presigned_upload_url`)
4. Использует `authorization_header` в заголовке `Authorization`
5. Bunny CDN автоматически обрабатывает видео
6. Bunny отправляет вебхуки на сервер при изменении статуса
7. Когда видео готово (статус `"ready"`), оно появляется в списке для подписчиков

### Процесс просмотра видео (Подписчик)

1. Подписчик запрашивает список видео через GET `/api/courses/videos`
2. Выбирает видео из списка
3. Запрашивает токен просмотра через GET `/api/courses/video/{video_db_id}`
4. Использует `bunny_video_id` и `watch_token` для встраивания плеера
5. Токен действителен до `expiration_time`

## Рекомендации для фронтенда

1. **Кеширование списка видео**: Список видео можно кешировать, но учитывайте, что новые видео могут появляться после загрузки

2. **Обновление статуса**: Если админ загружает видео, можно периодически опрашивать список или использовать WebSocket для обновления статуса (если будет реализовано)

3. **Обработка ошибок подписки**: При получении 403 на эндпоинтах просмотра - показывать сообщение о необходимости подписки

4. **Валидация токена**: Проверяйте `expiration_time` перед использованием токена. Если токен истек - запросите новый

5. **Обработка больших файлов**: При загрузке видео учитывайте, что файлы могут быть большими. Используйте прогресс-бар и обработку ошибок загрузки

6. **Отображение превью**: Используйте `thumbnail_url` для показа превью видео (если доступно)

7. **Форматирование длительности**: Преобразуйте `duration` (секунды) в читаемый формат (например, "5:30" или "1:25:10")

8. **Пагинация**: Реализуйте пагинацию для списка видео, используя `limit` и `offset`. Учитывайте `total` для расчета количества страниц

9. **Воспроизведение видео (КРИТИЧНО!):** 
   - Используйте **стандартный HTML5 `<video>` элемент** с `src={playback_url}`
   - **НЕ используйте embed iframe** (например, `iframe.mediadelivery.net/embed/player.js`) - это не поддерживается для secure token playback
   - Просто используйте: `<video src={playback_url} controls />`
   - См. полный пример кода выше в разделе "Пример использования на фронтенде"

## Формат дат

Все даты возвращаются в ISO формате: `"YYYY-MM-DDTHH:MM:SS"` (например, `"2026-01-06T12:30:45"`).

## Безопасность

- Все эндпоинты для просмотра требуют активную подписку
- Токены просмотра имеют ограниченное время жизни (60 минут по умолчанию)
- Загрузка видео доступна только администраторам
- Видео загружаются напрямую в Bunny CDN, не проходя через ваш сервер

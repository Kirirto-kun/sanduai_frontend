# КМЖ - Руководство для фронтенда

Краткое руководство по работе с обновленным API генерации поурочных планов (КМЖ).

## Эндпоинт

**POST** `/api/generate/kmzh`

**Требует авторизации:** Да (JWT токен в заголовке `Authorization: Bearer <token>`)

**Списывает токены:** Да (10 токенов за генерацию)

---

## Запрос (Request Body)

### Обязательные поля:

- `subject` (string) - Предмет (например: "Математика", "Қазақ тілі")
- `grade` (string) - Класс (например: "4", "10")
- `topic` (string) - Тема урока
- `teacher_name` (string) - Имя учителя
- `section_name` (string) - Раздел (Бөлім)
- `lesson_number` (integer) - Номер урока (положительное число)
- `learning_objectives` (array[string]) - Массив целей обучения с кодами
- `lesson_type` (string) - **НОВОЕ** Тип урока: "Жаңа сабақ", "Бекіту", "Қайталау" и т.д.

### Опциональные поля:

- `language` (string) - Язык ответа: "kazakh" или "russian" (по умолчанию: "kazakh")
- `date` (string) - Дата в формате **DD.MM.YYYY** (например: "15.01.2026")
  - Используется для автоматического определения ценности "Адал Азамат"
  - Если не указана - используется дефолтная ценность
- `textbook_images` (array[string]) - **НОВОЕ** Массив изображений страниц учебника в формате Base64
  - Формат: `["data:image/jpeg;base64,/9j/4AAQ...", "data:image/png;base64,iVBOR..."]`
  - Фронт должен конвертировать файлы в Base64 с префиксом `data:image/{тип};base64,`
  - Может быть пустым массивом `[]`
- `textbook_text` (string, nullable) - **НОВОЕ** Текст упражнений из учебника (если нет изображений)
- `preferred_platform` (string, nullable) - **НОВОЕ** Предпочитаемая платформа: "Kahoot", "BilimClass", "SanduAI.kz" и т.д.

## Ошибки

### 402 Payment Required
Недостаточно токенов. Нужно пополнить баланс.

### 400 Bad Request
Некорректные данные в запросе:
- Отсутствуют обязательные поля
- Неверный формат даты (должен быть DD.MM.YYYY)
- Неверный формат изображений

### 502 Bad Gateway
Ошибка при обращении к LLM или генерации плана.

---

## Что важно для фронтенда

### 1. Обязательные поля
Все поля, отмеченные как обязательные, должны быть заполнены. Без них запрос вернет ошибку 400.

### 2. Тип урока (`lesson_type`)
Это новое обязательное поле. Фронт должен предоставить выбор типа урока:
- "Жаңа сабақ" (Новый урок)
- "Бекіту" (Закрепление)
- "Қайталау" (Повторение)
- И другие типы по стандартам РК

### 3. Изображения учебника (`textbook_images`)
- Пользователь может загрузить несколько изображений (страницы учебника)
- Каждое изображение конвертируется в Base64 с префиксом `data:image/jpeg;base64,` или `data:image/png;base64,`
- Отправляется как массив строк
- Если изображений нет - отправлять пустой массив `[]`

**Пример конвертации изображения:**
```javascript
// Псевдокод
const file = input.files[0];
const reader = new FileReader();
reader.onload = () => {
  const base64 = reader.result; // Уже содержит "data:image/..."
  textbookImages.push(base64);
};
reader.readAsDataURL(file);
```

### 4. Дата (`date`)
- Формат: **DD.MM.YYYY** (15.01.2026)
- Используется для определения ценности "Адал Азамат" автоматически
- Если не указана - будет использована дефолтная ценность
- Может быть `null` или не передаваться

### 5. Язык (`language`)
- Значения: "kazakh" или "russian"
- По умолчанию: "kazakh"
- Фронт может предоставить выбор языка ответа

### 6. Предпочтительная платформа (`preferred_platform`)
- Опциональное поле
- Если указана - ИИ будет приоритизировать эту платформу в заданиях
- Может быть: "Kahoot", "BilimClass", "SanduAI.kz", "Mentimeter", "Quizlet", "Wordwall"
- Или `null` - ИИ выберет платформу сам

## Последовательность работы

1. **Форма ввода данных:**
   - Заполняются обязательные поля
   - Выбирается тип урока
   - Опционально: загружаются изображения учебника
   - Опционально: выбирается язык ответа
   - Опционально: указывается дата

2. **Отправка запроса:**
   - Проверить баланс токенов пользователя
   - Отправить POST запрос с данными
   - Показать индикатор загрузки (генерация может занять время)

3. **Обработка ответа:**
   - Если успех (200) - показать план урока
   - Если 402 - показать сообщение о недостатке токенов
   - Если 400 - показать ошибки валидации
   - Если 502 - показать сообщение об ошибке генерации

4. **Редактирование и экспорт:**
   - Пользователь может отредактировать план
   - Отправить на `/api/generate/kmzh/docx` для генерации DOCX файла

---

## Проверка баланса токенов

Перед отправкой запроса рекомендуется проверить баланс:

**GET** `/api/tokens/balance`

Если баланса недостаточно (меньше 10 токенов), показать предупреждение или заблокировать кнопку генерации.

# SanduAI Parent Meeting Pro — план реализации

Дата: 7 ноября 2026. Основание: полное ТЗ заказчика «АТА-АНАЛАР ЖИНАЛЫСЫНЫҢ КӘСІБИ КОНСТРУКТОРЫ» (15 разделов).

## Результат

Учитель или воспитатель получает готовый к проведению пакет родительского собрания, адаптированный к теме, возрасту детей, цели, формату и выбранной длительности. Пакет содержит реальные тексты и инструкции, а не предложения педагогу самостоятельно дописать материалы.

## Этапы

1. **Контракт и генерация.** Обязательные организация (школа/детсад), класс/группа, тема и длительность; дополнительные участники, цель, восемь видов собрания, очный/онлайн/смешанный формат, период учебного года, вопросы, специалисты, ресурсы, особые пожелания. Начальные параметры используются только с явным согласием; допущения показываются в результате.
2. **Полный пакет.** Паспорт, творческая идея, поминутный план, девять этапов с готовыми репликами и переходами, психологический тренинг, минимум два разных практических задания с заполненными примерами, жизненный кейс, игра с вопросами/правилами, рефлексия и заключение. Для короткой встречи этапы объединяются; сумма минут равна выбранной длительности.
3. **Материалы.** Приглашение, план 8–12 слайдов с текстом и визуальными рекомендациями, карточки тренинга, анкета 5–10 вопросов с вариантами ответов, рабочие листы, лист рефлексии, незаполненный протокол, 5–7 практических советов. Неизвестные дата/время/место и фактические решения не выдумываются.
4. **Интеграция.** Существующие авторизация, фоновые задания, идемпотентная оплата, возврат при ошибке, история, повторное открытие и защищённый Word-экспорт. Раздел доступен в навигации; новая генерация не требует подписки на библиотеку.
5. **Интерфейс.** RU/KK, понятные обязательные поля, дополнительные настройки по запросу, сохранение черновика на пользователя, состояния загрузки/отмены/ошибки, оглавление результата, копирование и скачивание. Адаптивная верстка, клавиатура, видимый фокус, доступные подписи и сокращённая анимация.
6. **Проверка.** Контракты запроса/результата, точный тайминг, материалы, доступ владельца/чужого пользователя, история и экспорт; frontend tests/lint/typecheck/build и backend tests/lint; локальная проверка браузером на desktop/mobile и обоих языках, визуальная проверка Word.

## Педагогические ограничения

Участие добровольное. Нельзя сравнивать детей, обвинять родителей, разглашать семейные тайны, ставить диагнозы, выдумывать статистику, источники, правовые требования или данные конкретных детей. Ценности Казахстана отражаются в действиях. Для цифрового инструмента предлагается конкретная цель и офлайн-альтернатива. Протокол — только шаблон для фактически состоявшегося собрания.

## Git и запуск

Небольшие тематические коммиты и push в `codex/parent-meeting-pro` обоих репозиториев. Сохраняется существующая работа Coaching Pro. Продакшен не разворачивается; ветки `production` не изменяются. Итоговый запуск — frontend на localhost:3000 и backend на локальной БД/Redis, с явным API base.

# Zerde Pro — интерфейс

Локальная версия от 30 октября 2026. Production не развёрнут.

Открыть [http://127.0.0.1:3000/dashboard/ai/zerde](http://127.0.0.1:3000/dashboard/ai/zerde) после обычного входа в локальный аккаунт SanduAI.

## Возможности

- 14 режимов методической помощи, kk/ru, проверка классов 2–8 и команды из двух авторов одной возрастной категории.
- Паспорт проекта, свои материалы и реальные вложения; черновик браузера и сохранение в аккаунте с повторным открытием.
- Бесплатные проверки правил, честные статусы доступных доказательств и восемь типов шаблонов DOCX/PDF.
- Персональная консультация ИИ с видимой ценой из каталога, подтверждением обезличивания, очередью, восстановлением и отменой.
- Постоянный журнал фактической AI-помощи; автор редактирует место использования, проверку и собственные изменения, а декларация использует реальные записи.
- Диаграммы с исходными значениями и доступной таблицей, адаптивный экран и reduced motion.

Готовую конкурсную работу, результаты, опыт ученика или научные выводы ИИ за автора не пишет. Пустой шаблон, загруженный файл и подтверждённое соответствие отображаются как разные состояния.

## Локальный запуск

1. Запустить локальный FastAPI на `127.0.0.1:8000`, PostgreSQL и Redis; применить backend-миграции только к локальной БД.
2. Для frontend установить `NEXT_PUBLIC_API_BASE=http://127.0.0.1:8000` в локальной конфигурации.
3. Выполнить `npm run dev` и открыть маршрут выше. Обычная аутентификация сохраняется.

Для настоящей AI-консультации backend должен иметь рабочий AI-провайдер и включённый исполнитель длительных заданий. Стоимость берётся из API; на момент приёмки три реальные консультации списали по 10 монет на локальных тестовых аккаунтах.

## Проверено

Полный frontend-набор: **682 теста / 99 файлов**; TypeScript, весь ESLint и сборка **76 маршрутов** — успешно. Браузером проверены загрузка, проверка, скачивание, история, восстановление файлов и черновика, диаграммы, kk/ru на 390 px, а также настоящий платный AI-сценарий через очередь до результата. Через API прошли 28 сочетаний режима и языка, 32 скачивания и отрицательные проверки файлов/доступа. Все 16 DOCX и 16 PDF базовых шаблонов просмотрены после рендера.

Проверено: два разных пользователя одновременно экспортировали свои PDF и загрузили их обратно для проверки. Каждый получил только свои данные; чтение чужого файла отклонено, основной сервер отвечал во время обработки. Нативная PDF-библиотека запускается в отдельных процессах с ограничением параллельности, времени и размера результата; проверены остановка, отмена и возврат ошибок.

## Источники и границы

Официальные правила: [қазақша](https://daryn.kz/pol514/Zerdekz.pdf), [по-русски](https://daryn.kz/pol514/Zerderu.pdf), приказ 09.09.2026 №153. Интерфейс показывает известные несогласованности первоисточника и различает административную/обезличенную копии.

OCR, внешняя проверка антиплагиата, подлинность подписей, согласий и полное выявление персональных данных не обещаются. Непрочитанный материал не считается проверенным. Для PDF backend требует установленный Times New Roman; перед будущим Linux-развёртыванием наличие шрифта и рендер проверяются заново. Локальная сборка не является публикацией.
